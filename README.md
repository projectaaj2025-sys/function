# МатАнализ 10–11

Интерактивный курс: предел и непрерывность, производная, применение производной, первообразная и интеграл, дифференциальные уравнения. Три языка (RU / KK / EN), светлая и тёмная темы.

Статический сайт без сборки: откройте `index.html` или включите GitHub Pages для ветки (Settings → Pages → Deploy from a branch → `/root`).

- `js/topics.js` — список тем и коды целей обучения
- `js/content.{ru,kk,en}.js` — теория
- `js/tasks.js`, `js/tasks2.js` — генераторы задач с пошаговыми решениями
- `js/labs.js` — симуляторы
- `js/app.js` — оболочка, проверка ответов, тренажёр, контрольная, прогресс, справочник формул
- `js/extra.js` — слайды урока, графический калькулятор на JSXGraph (`vendor/jsxgraph`, MIT/LGPL, работает офлайн), задачи «по рисунку», истории к темам
- `js/more.js` — уроки «Второй замечательный предел», «Приближённые вычисления», «Прикладные задачи на ДУ», полный урок «Исследование функции», задачи с практическим содержанием
- `js/more2.js` — полные цели обучения, алгоритмы решения, интересные факты, графики в теории и на слайдах
- `js/ai.js` — ИИ-наставник (ключ пользователя хранится только в браузере)
